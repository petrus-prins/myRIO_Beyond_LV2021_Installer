Connection Parameter String

The CORBA parameters
The main entry to connect to the Server is the corba tag including everything you need to contact the corba interface itself
TagName Attributes Default Value SubTags
corba typ="[nameserver|locator|file|nameserverurl|sessionior]"
  • nameserver : Very common conection method for which you need a server, port and path
  • locator : Is the standard interface defined by CORBA which also uses a server, port and path in most environments both locator and nameserver behave in the same way
  • file : Connect by using a file including a corba IOR file. This can be used as a last resort if all other connection types do not work
  • nameserverurl = specify a user-defined url. If you use nameserver or locator, I will generate this url for you. Here you have the option to insert other URLs unknown to me
  • sessionior : IOR of a session or a file including it
If the typ attribute is ommited it is assumed that the corba tag contains
  • Corba IOR to AoFactory or AoSession
  • full qualified corbaname url
SubTag Attributes Description
Path The path of the locator or the namesever, the url or the filename of the IOR file. This tag contains info on the choosen connection type
Server port="[number]" : The number of the port to connect to
On most orbs the default number is commonly 900 while the default defined by the Object Managment group is 2809.		 Server name or IP
Additional Parameters
TagName Attributes Default Value Description
user The user to connect to the AoSession. This is used if ASAM security is switched on
pwd e="[1|0]" Set this attribute to 1 if you do not want to be prompted to give a password
c="[1|0]" Set this attribute to 1 if the given password is crypted		 e="0"
c="0"		 The password to connect to the AOSession. This is used if ASAM security is switched on
additionalauth During creation of a new session a set of parameters is handled to the server. It is ',' separated conataining NAME=VALUE. e.g. "abc=1,def=hallo"
A documented ASAM ODS parameter is the following:
 <additionalauth>CREATE_COSESSION_ALLOWED=TRUE</additionalauth>
USER and PASSWORD are automatically added if <user> or <pwd> is used.
openmode DEPRECATED: In old ODS documentation a parameter openmode=??? occured. It is used during creation of a new session in the auth string. Please use "OPENMODE=???" in additionalauth parameter
cfg loglevel="[0...3]" is used to set the loglevel of the plugin. 0 is switched off. Microsofts DbgVIEW.exe can be used to trace the logging output during use of the plugin. loglevel="0" Name of the logfile that is flushed when the plugin is closed.
modelaccess ApplicationStructureValue [ApplicationStructureValue|ApplicationStructure]
  • ApplicationStructureValue: Receives the application model with one server call.
  • ApplicationStructure: Use the OO API to retrieve the model. Because this will cost a lot of server calls it is very slow. Do not use this setting if your server supports ApplicationStructureValue
geninvsql Give a filename like "C:\inverse.sql"
This optin can be used in combination with ApplicationStructureValue to generate an SQL script template including the missing inverse relations of the model. The script can be examined to see if there are real elements missing in the svcattr or svcref table of the database
benchmarkcalls no [yes|no]
To get an impression of how much time is used while comunicating with the server, this parameter can be set to yes. The plugin will dump a time statistic to the logfile which gives you an impression of the time the plugin itself including the server comunication consumed
cacheentitiesforsession Sometimes it is useful to call "ODSDialogRefresh srcHandle" to empty the cache of a source because changes on the server should reach DIAdem.
It may be useful to exclude some Entity types from this refresh to avoid them being removed from the cache. A very good example is Unit, PhysicalDimension, User. It is not assumed that they will change during one session while the name of a measurement may change.
If you exclude them from refresh this does not mean that a new User or Unit will not appear but that you will not get the changes if User Mayer changes the name to Meyer during the session.
usequerytobrowse asterix="[yes/no]"
If asterix is set to yes, the extended query contains "*" instead of a list of attributes.		 ext [yes|no|ext]
Some servers do not implement the Normal/Extended Query interface of ASAM ODS OO API. On those servers the Object oriented API has to be used. By default the plugin uses an extended query to browse the data. The object oriented interface has proved to be slow and memory consuming on server and client. So if the server does not support the query interface, you have to switch to the object oriented api by setting this option to no. Using an actual ASAM Server there should be no problem in using an Extended Query! The Horiba Stars Server does not support extended queries. Therefore you have to choose OO-API or Normal-Query to browse. Otherwise the browser will be empty!
globalcommit yes [yes|no]
Determines if each instance is embedded in an own transaction or if a transaction is opened on the first write access to the server and closed on commit. The default will transmit transactions only on commit. Change this option to "no" if you want more control on when which instance is created.
setinversereferences no [yes|no]
An ASAM Ods server normally only expects the parent relation to be set. It is also possible to set the child relations. Because of some problems when both relations are set and because of performace issues, the default behavior is changed to set only the parent relations. Child relations are now ignored by the plugin. If problems occur in the script code you can switch back to the old behavior by setting this setting to "yes".
ignorevalueflags no [yes|no]
If you know that your data does not contain value flags you can switch the plugin to a mode were the value flags are ignored. This is recommended because the Avalon server always returns flag values if they exist or not.
usevaluematrix
  • maxstringsize="[0..25000]" : The stringsize in characters is used to decrease the chunksize if strings are accessed. This is used because the serialization of strings might blow memory. So it may be possible to retrieve 200000 double values but it may be impossible to retrieve 200000 strings of the length 10000 charcters. The default value 0 is used which means there will be no difference in chunk size for all datatypes.
  • maxtransportbytes numeric value that defines the max size of data that should be retrieved from value matrix in one piece. The calculation is done rowcount*columncount*8. The default value is 262144000 (256 MB)
 0 positiv integer number
If it is known that the channels might become very long, it is possible to use the ValueMatrix.getValueVector instead of the InstanceElement.getValue method. With this setting you can adjust the block size of the getValueVector method. A good value would be 200000. If this attribute is set to 0 or is missing, the InstanceElement.getValue is used.
cachemeasurement metaonly [metaonly|byquery|bydatatypequery|byvaluematrix|no]
If a measurement is loaded into DIAdem, the plugin gets an event and loads all necessary data into its cache to speed up loading
  • metaonly : AoMeasurement/AoMeasurementQuantity/AoSubmatrix/AoLocalColumn attributes and relations are retrieved by some queries
  • byquery : Uses metaonly and retrieves id/values/generation_parameters/flags of localcolumns by extended queries. The queries are bundled by the datatype of the values and INSET condition with localcolumn ids
  • bydatatypequery : Uses metaonly and retrieves id/values/generation_parameters/flags of localcolumns by extended queries. The queries are bundled by the datatype of the values and the submatrix id
  • byvaluematrix : Uses metaonly and the Valuematrix is used to get the values and flags of the local_columns of a single submatrix in two server calls
  • no : Do not do anything which will result in a lot of server calls to load the measurement
attributesbyqueryinterface yes [yes|no] If the ... is pressed in the DIAdem query interface, this can be resolved by a user-defined interface or be emulated by the default access. This interface will ignore all changes done to the cache and will return only the server results.
If you determine problems when using the ... button with the new plugin, it may be useful to switch it to 'no'. But this will slow down the operation.
contextparameter This contains a list of string context parameters that are set to the session after the model has been loaded from the server.
Example: 'ROWS=all;INITIALIZE=yes;DEBUG=no'
orderbyattributes This is a list of entity attribute pairs that offer the ability to define one attribute for each entity which should be used as default orderby in each query.
Example: 'Measurement=name;Channel=id'
serversupportsunicode no [yes|no] If the server supports UNicode and the Oracle database is configured to use UNICODE, the server will tell the client by using the environment variable SERVER_CHARSET=UTF8 that unicode is supported. Using this parameter writing of unicode can be enabled even if the server does not return the context variable.
blobandbytestreamattributes no [yes|no] blob and bytestream attributes are returned as base64 strings. This might cause memory issues. This option allows it to disable blob and bytestream attributes to show up in models if set to yes. Be aware that the server might only return the blob if usequerytobrowse=no and attributesbyqueryinterface=no is used. Best practice is to open a store twice. Once only to retrieve blob values. Close it afterwards to avoid huge memory usage.
usegetvalueseqforlc yes [yes|no] If values/flags/generation_parameters attributes are retrieved (no additional caching mode active) InstanceElement::getValueSeq is used to retrieve all three attributes with one call. Setting this to "no" retrieves each one of them in a single server call of InstanceElement::getValue
useattributeinvalidflag no [yes|no] The server returns a flag with each attribute value in order to mark them as invalid. If this property is set to "yes", the attribute stays empty instead of containing the value returned or "NOVALUE" for STrings or NaN for double/float.
authtoken
  • GSSTOKEN: To allow a single sign on with kerberos authentification, openMDM uses a special form of password. It starts with the text 'GSSTOKEN:' followed by a base64 encoded kerberos ticket generated for a given SPN('Service Pricipal Name'). To allow this kind of authentification, parameters are specified with this token.
    e.g. '-spn HTTP/myHost.com' will send a ticket for the specified service principal name.
  • CERTTOKEN: To allow a single sign on using a certification card, openMDM uses a special form of password. It starts with the text 'CERTTOKEN:' followed by a base64 encoded certificate. To allow this kind of authentification, parameters are specified with this token.
    e.g. '-mode CERTTOKEN' will send a generated certificate.
By use of '-prefix ABC:' the default token (e.g. 'GSSTOKEN:') is changed to an alternative value.
basemodelversion 29 USI kernel can be influenced with this parameter.
- start_offset & flags_start_offset will become LONGLONG if greater 29.
supplementenumsbyoocalls yes [yes|no] if server does not support AoSession.getEnumerationStructure and AoSession.getEnumerationAttributes OO methods are used to retrieve the enumerations. This causes a lot of server calls if a lot of application enumeration attributes are used. To avoid this it can be disabled. The D?_ENUM attributes will then show up as DT_LONG. This parameter can only be used in scripts. There is no GUI control.
writemetausingapplelemaccess
  • bulk="yes" : if this attribute is set to 0 'values', 'flags' and 'generation_parameters' are written using InstanceElement::setValue instead updateInstances.
 no [no|yes] If this is set to yes ApplElemAccess::insertInstances and ApplElemAccess::updateInstances are used instead of InstanceElement::createInstance and InstanceElement::setValue to write data.
ignoresequenceattributes no [no|yes] Sequence attributes are stored in additional database tables. Normal access always retrieves all attributes. Because sequence attributes are expensive on server side and most times are not necessary to work it is possible to disable them in the model. Just the local column has some of them that have to stay.
classicmodejoins no [no|yes] Since first version of the AOP5 plugin the joins going over an child relation are entered the wrong way round (not inverted). This has been fixed. If this causes trouble this parameter can be used to set back to old mode.
createcosession no [no|yes] This can be used in combination with an session IOR. Instead of taking ownership of the session, a copy of the session will be created. Be aware that this is only possible if the original session has the right to create a cosession.
closesessiononclose yes [no|yes] If this parameter is set to no the AoSession::close method is not called. This might be helpful in Boss/worker model. Be aware that you have to make sure the session is closed to avoid waste of server resources.
supressunitandquantitymqnrelation no [no|yes] When writing to ODS server using dataStore API the measurment_quantities relation is accessed. To avoid this this attribute can be set to yes.

                <server port="900">AOPServer</server>

Plugin Context

By retrieving context 300, some plugin specific information can be retrieved.

Vbs example

        Option Explicit

        dim store : set store = navigator.Display.CurrDataStore.GetDataStore
        dim context : set context = store.GetContext(300)

        dim oldDebugLevel : oldDebugLevel = context.GetParameter("DEBUGLEVEL")
        'increase loglevel to max
        call context.SetParameter("DEBUGLEVEL", 3, DataTypeInt32)
        ' do some stuff
        ' .....

        call context.SetParameter("DEBUGLEVEL", oldDebugLevel, DataTypeInt32)

TOKEN passwords

In OpenMDM different kinds of passwords are used for using single sign on.
  • GSSTOKEN: Use additional parameter 
    <authtoken>-spn HTTP/myHost.com</authtoken>
    to make Service Principal Names known to the plugin.
  • CERTTOKEN: Use additional parameter 
    <authtoken>-mode CERTTOKEN</authtoken>
    to make the plugin generate an CERTTOKEN.

Column Oriented query

With DIAdem 2015 column oriented query (DataStore.GetElementProperties, DataStore.SearchProperties) is supported. If DisableValidation is called it is also alloed to use some prefixes to attribute path.
  • Aggregates: COUNT, DCOUNT, MIN, MAX, AVG, STDDEV, SUM, DISTINCT
  • Additional: GROUPBY, ORDERBY, ORDERBYDESCENDING, OUTERJOIN
It is also possible to add a virtual result column "NI_USI_INSTANCEKEY" to return instance keys of the result elements. Those can be resolved using DataStore.GetElementByKey and will also automatically add a GROUPBY to the result columns to avoid duplicates. Example: 
    dim query : Set query = store.CreateQuery(eDataStoreQuery)
    query.ReturnType = "Kanal"
    query.Conditions.Add "Kanal", "id", "<>", 0

    set resultColumns = store.CreateResultsColumns
    resultColumns.DisableValidation
    resultColumns.Add("Kanal", "ORDERBY(DISTINCT(name))")

    store.SearchProperties(query, resultColumns, 10000)
    navigator.LoadProperty store.ResultsProperties

IOP-SSL

The used CORBA ORB - OmniORB supports IOP-SSL. If the Connection is set to "URL or IOR" connection can be done using: 
corbaname:ssliop:1.2@myServer.company.com:28090/NameService#ODS_INSTANCE_NAME.ASAM-ODS
In the connection string it will look like: 
<corba>corbaname:ssliop:1.2@myServer.company.com:28090/NameService#ODS_INSTANCE_NAME.ASAM-ODS</corba>

Browse SSL-IOP nameservice

If you want to use the Browse button to figure out ODS_INSTANCE_NAME please pick "Nameservice URL" and insert: 
corbaloc:ssliop:1.2@myServer.company.com:28090/NameService
afterwards it is possible to use the "..." button to view the content of the CORBA name service.

Configuring the certificates

Copy the default config file 
C:\Program Files\National Instruments\Shared\USI\DataPlugins\AOP5\uspAOP5_omniorb.cfg
to 
C:\ProgramData\National Instruments\Shared\USI\Plugins\DataPlugins\AOP5_64\uspAOP5_omniorb_custom.cfg
and adjust it to your needs. The file contains some documentation on the ssl??? needed to configure the system. As a minimum you need to provide an sslCAFile containing the required certificates.

Relevant configuration entries

nameDescription
sslCAFileSpecifies the file containing the SSL Certificate Authority certificate
sslKeyFileSpecifies the file containing the SSL key
sslKeyPasswordSpecifies the password to unlock the key
sslVerifyModeSpecifies the verify mode, as given to SSL_CTX_set_verify. Valid values are "none", representing SSL_VERIFY_NONE, and "peer", representing SSL_VERIFY_PEER. If you select peer, additional options "fail" and "once" can also be specified, corresponding to SSL_VERIFY_FAIL_IF_NO_PEER_CERT and SSL_VERIFY_CLIENT_ONCE, respectively.

  • Added ability to ignore the value flag vector. Because the athos server always returns value flags, the plugin can be told to ignore the value flags if it is known that no value flags were used. This can speed up the loading of bulk data because it reduces the amount of data to be transfered over the network.
  • Enumerations are now written as enumVal, enumSeq if the attrbute is marked as DT_ENUM(30) in the svcattr table. This change is only relevant for writing applications!

FAQ

  • I am connected to an Horiba STARS Server but I can't browse the tree.

    The Stars Server has to be configured to use NormalQuery or OO-API in browse mode to successfully be browsed or worked with.

  • I have very long measurment quantities and I am not able to import them.

    Please go to the advanced dialog bpox and configure the block size for ValueMatrix access. This will cause the plugin to access the data in chunks instead of one piece.

  • How can I debug the plugin

    • Use Microsoft/Sysinternal DbgView to watch the plugin work. Warnings and errors were logged independent on the log settings of the plugin.
    • Use code like the following one to increase the debug level of a HighQSoft Athos server. 
              dim oldAthosDebugLevel : oldAthosDebugLevel = store.GetContext.GetParameter("DEBUGLEVEL")
        store.GetContext.SetParameter "DEBUGLEVEL", 10, DataTypeInt32
        ' Do code where the error occures
        store.GetContext.SetParameter "DEBUGLEVEL", CInt(oldAthosDebugLevel), DataTypeInt32
    • To determine the version of the HighQSoft Athos server, use the following code: 
      MsgBox store.GetContext.GetParameter("ATHOS_VERSION")

  • How can I solve problems with database constraints?

    The DataStore.Save method allows a list of entities to be attached. 
    store.Save "PhysicalDimension;Unit;Quantity;NI_MEASUREMENT_TREE"
    Will make sure that new Units are created before the Quantities before the main hierarchy.
